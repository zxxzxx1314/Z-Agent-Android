# Z-Agent 完整工程包：设置模型名称（Model Name）+ 微信/QQ 风格 UI

本包为**可直接推送 GitHub Actions 编译的完整工程**（Kotlin + Chaquopy Python），
已包含 Gradle 构建文件、AndroidManifest 与全部 Kotlin/Python/资源文件。

## 一、本次更新内容（相对您手上的 v6.1 工程）

1. **设置弹窗新增「设置模型名称」**（第 3 项，现共 5 项）：
   设置 API Key / 设置 API 地址（Base URL）/ **设置模型名称（Model Name）** / 清空会话 / 查看状态
   - 模型名保存到 `SharedPreferences("zagent")` 的 `model_name` 键；
   - 每次启动引导完成后自动同步到 Python 层；
   - 顶栏状态显示「模型 xxx」；留空保存 = 恢复出厂默认 `deepseek-flash`。
2. **PythonBridge.kt 新增 `setModel()`**：统一空安全写法 `callAttr(...)?.toString() ?: ""`，
   规避 Chaquopy 平台类型（PyObject!）空安全报错。
3. **Python 层去硬编码**：`MODEL` 改为三级优先级
   **环境变量 RAIN_MODEL → mind/config.json 的 model 字段 → DEFAULT_MODEL**；
   新增 `set_model()`（config 持久化 + 热更新 `zag.MODEL`），`get_status()` 返回 `model` 字段。
4. **UI 重排为微信/QQ 式三段布局**（无任何 Emoji）：标题栏+状态副标题+右上角设置 /
   横向滚动功能胶囊条 / 对话区自动贴底 / 底部圆角输入栏+发送按钮。

## 三、模型名数据流（三层落点）

```
设置弹窗输入 ──→ SharedPreferences("zagent", "model_name")   UI 持久化
            └─→ PythonBridge.setModel(ctx, name)             Kotlin 桥（空安全）
                 └─→ zagent_app.set_model(name)              Python 入口
                      ├─ 写入 mind/config.json {"model": name}  跨重启持久化
                      └─ 热更新 zag.MODEL                      本轮 chat 立即生效
                           └─ payload = {"model": MODEL, ...}   请求实际使用
重启 App：bootstrap → config.json 的 model → zag.MODEL（同样生效）
```
